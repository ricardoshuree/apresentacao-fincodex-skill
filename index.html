Funcionalidades

Tudo que uma apresentação
executiva precisa.

Do outline ao arquivo final em 3 fases. O Claude cuida do design, você cuida da narrativa.

⌨
Motor de Navegação
Teclado, swipe touch, dots clicáveis e barra de progresso olive. Funciona em qualquer browser, sem instalação.
← → swipe dots
📋
Roteiro Popup
Botão R abre uma janela separada com timer, sincronização automática com o slide ativo e estimativa de tempo por slide.
timer · sync · HH:MM:SS
◑
Toggle Claro / Escuro
Alternância em runtime sem recarregar. CSS variables trocadas globalmente em milissegundos.
runtime · sem reload
📊
Line Chart Interativo
Crosshair que segue o mouse via SVG + mousemove. Valor dinâmico atualizado em tempo real. Área com glow e projeção pontilhada.
crosshair · SVG · Bézier
⚙
Gauge Canvas 2D
Ponteiro animado via canvas. 4 variantes: base, numérico, textual por zona e dashboard KPI.
canvas · 4 variantes
▶
Isometric Conveyor
Esteira animada com cubos coloridos por estado — success, running, pending, error. Metáfora visual para pipelines de dados.
SVG · animação CSS
⬡
Pipeline com Estados
Nós coloridos com animação de fluxo entre etapas. Estados: active, ok, error, pending.
pnode · pdot · pedge
▮
Terminal & Code
Diff colorido, cursor blink, REPL, stream de saída. Ideal para slides técnicos e de engenharia.
diff · REPL · blink
◎
Charts Tab Switcher
Bar, Linha e Donut com troca animada via tabs. Legenda interativa com destaque por clique.
bar · line · donut

Instalação

De zero ao primeiro deck
em 3 minutos.

Funciona no Claude Desktop para macOS e Windows com conta Pro ou Team.

01
Baixar e descompactar
Faça o download do arquivo ZIP e descompacte em uma pasta de sua preferência.
apresentacao-padrao-fincodex-skill.zip
02
Abrir o Claude Desktop
Acesse as configurações do Claude Desktop e navegue até a seção de Skills.
Claude → Settings → Skills → Add Skill
03
Selecionar o skill.md
Navegue até a pasta descompactada e selecione o arquivo skill.md. O skill aparecerá na lista como apresentacao-padrao-falconi.
→
Começar a usar
Inicie uma conversa e descreva o que você quer apresentar. O Claude guia você pelas 3 fases: Plano → Design → Montagem.
